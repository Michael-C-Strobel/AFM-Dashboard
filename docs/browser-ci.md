# Synthetic browser CI

`tests/browser-ci.mjs` creates a six-pixel GWYP measurement in a unique temporary directory. Heights are 0–5 nm, lateral extent is 3 × 2 µm, and units are metres. The fixture is generated from code; no laboratory or external sample files are required or redistributed.

The test starts its own server on **127.0.0.1:4175**, or `AFM_TEST_PORT` when supplied (for example 4177). Ports must be integers from 1024 through 65535; demo port 4173 is refused. Keep this port free; an existing server is not reused or stopped. The script closes its browser/server and deletes its primary generated fixture directory on success or failure. The model-context child test retains its synthetic fixture/audit scratch directory under `/tmp` for inspection. Port 4173 is unaffected.

## Run locally

Provide an existing Playwright installation and select `PLAYWRIGHT_BROWSER=chromium|firefox|webkit` (default `chromium`):

```sh
PLAYWRIGHT_MODULE=/absolute/path/to/playwright/index.mjs \
PLAYWRIGHT_BROWSER=chromium \
PLAYWRIGHT_EXECUTABLE=/absolute/path/to/chrome \
AFM_TEST_PORT=4177 node tests/browser-ci.mjs
```

`PLAYWRIGHT_EXECUTABLE` optionally overrides the selected engine's executable. The older `PLAYWRIGHT_CHROMIUM_EXECUTABLE` remains supported only for Chromium; it is ignored for Firefox/WebKit. Omit overrides to use Playwright's matching downloaded browser. `PLAYWRIGHT_BROWSERS_PATH` can isolate downloaded binaries in a temporary cache. Unknown engine names fail before starting a server. The output records both browser engine and version. Playwright is test tooling, not an application dependency.

## Coverage

The test routes only the data manifest to an empty file list and rejects repository measurement requests. It imports generated bytes through the file input and exercises the real browser worker and scientific engine. It checks calibration, known mean/Sa/Sq/range/count/area, mean subtraction, downloaded recipe replay through the API and file input, and output/measurement identities.

It also validates and runs the Assistant's measurement starter with strict replay, checks source/output hashes, captures the processed surface for threshold segmentation with exact area/labels, checks captured PSD/ACF, dual-recipe registration and explicit sensitivity alternatives, opens/closes expanded inspection with Escape focus restoration, navigates all eight inspection tabs using the keyboard, and checks horizontal overflow at 390-pixel mobile width. Browser console errors and uncaught exceptions fail the test.

Portable recipe save/upload/replay is covered alongside legacy recipes. The entry point also runs `tests/browser-model-context.mjs` with the same browser engine and isolated server: two generated sources, an intercepted same-origin mock provider, explicit multi-source planning/execution, opt-in verified claims, source revocation, evidence links and audit/history checks. No live provider or credentials are needed. `AXE_CORE_PATH` optionally enables populated desktop/mobile model-context checks when invoking that test directly.

## GitHub Actions

`.github/workflows/test.yml` uses a Chromium/Firefox/WebKit matrix with independent results (`fail-fast: false`). Each job runs `npm test`, installs **Playwright 1.55.0** in the runner's temporary directory, installs its matching engine with `--with-deps`, then runs the same synthetic browser assertions. Application runtime dependencies remain unchanged. Each job also runs `tests/browser-preview.mjs`, which builds and extracts the local preview and verifies the packaged viewer and synthetic replay independently of the development checkout.

This checks a small native GWYP workflow across the three browser engines. Vendor fixtures, large datasets and complete accessibility audits remain separate checks. Hosted execution still requires a pushed workflow run.

Downloads used `apt-get download PACKAGE=VERSION` from `/tmp/afm-webkit-libs/packages`. Each `.deb` was extracted with `dpkg-deb -x PACKAGE.deb /tmp/afm-webkit-libs/prefix`. These versions reflect the local package index; this is a record of the successful experiment, not a requirement to downgrade another system. The second round supplied the four transitive dependencies of `libavif13`.

Two launcher details mattered. Playwright 1.55.0 checks dynamically loaded x264 using global `/sbin/ldconfig -p`, which does not reflect this temporary prefix. Actual library loading was verified with `ctypes.CDLL` under the local `LD_LIBRARY_PATH`. Also, the bundled `minibrowser-wpe/MiniBrowser` shell wrapper replaces `LD_LIBRARY_PATH`. A separate `/tmp/afm-webkit-libs/run-webkit.sh` preserved the bundle's environment and added the local prefix:

```sh
#!/bin/sh
WEBKIT_LOCAL_ROOT=/tmp/afm-cross-browser-cache/webkit-2203/minibrowser-wpe
export WEBKIT_EXEC_PATH="$WEBKIT_LOCAL_ROOT/bin"
export WEBKIT_INJECTED_BUNDLE_PATH="$WEBKIT_LOCAL_ROOT/lib"
export WEBKIT_INSPECTOR_RESOURCES_PATH="$WEBKIT_LOCAL_ROOT/share"
export WEBKIT_FORCE_COMPLEX_TEXT=1
export LD_LIBRARY_PATH="/tmp/afm-webkit-libs/prefix/usr/lib/x86_64-linux-gnu:$WEBKIT_LOCAL_ROOT/lib:$WEBKIT_LOCAL_ROOT/sys/lib"
exec "$WEBKIT_LOCAL_ROOT/bin/MiniBrowser" "$@"
```

After making that local wrapper executable, the passing invocation was:

```sh
LD_LIBRARY_PATH=/tmp/afm-webkit-libs/prefix/usr/lib/x86_64-linux-gnu \
PLAYWRIGHT_SKIP_VALIDATE_HOST_REQUIREMENTS=1 \
PLAYWRIGHT_MODULE=/tmp/groups-dashboard-npm-cache/_npx/fd3bca3c548369c0/node_modules/playwright/index.mjs \
PLAYWRIGHT_BROWSERS_PATH=/tmp/afm-cross-browser-cache \
PLAYWRIGHT_BROWSER=webkit \
PLAYWRIGHT_EXECUTABLE=/tmp/afm-webkit-libs/run-webkit.sh \
AFM_TEST_PORT=4177 node tests/browser-ci.mjs
```

This bypasses only the incompatible host-cache heuristic, not application or numerical checks. WebKit reported version **26.0** and passed import, calibrated measurements, strict replay/export, all scientific panels, expanded inspection/Escape, keyboard tabs and mobile overflow. No browser bundle files were edited. The hosted matrix continues to use normal `--with-deps` installation and does not require this local workaround.
