Measurement

Supported subsets: Gwyddion GWYP, NanoScope raster, calibrated IBW v5 images, and JPK TIFF raster. Other instrument configurations are unverified; ordinary TIFF images are unsupported. File contents determine format; numeric filenames such as .001 are accepted.

Original files stay unchanged. Every operation is recorded in a replayable recipe.

Import support

Load a measurement to inspect format and configuration support.

Processing

Recorded manual three-point choices, available for the supplied raw height channel only.

A deterministic starting point; not an assumed reproduction of the chemist’s manual leveling.
