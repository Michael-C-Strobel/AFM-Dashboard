Measurement

Supported formats & import help

Supported subsets: Gwyddion GWYP, NanoScope raster, calibrated IBW v5 images, and JPK TIFF raster. Other instrument configurations are unverified; ordinary TIFF images are unsupported. File contents determine format; numeric filenames such as .001 are accepted.

Original files stay unchanged. Every operation is recorded in a replayable recipe.

Import support

Load a measurement to inspect format and configuration support.

Processing

Recorded manual three-point choices, available for the supplied raw height channel only.

A deterministic starting point; not an assumed reproduction of the chemist’s manual leveling.

                Moving → fixed physical shift
                
    
                  
                
    
                
    
                  Use the captured lateral unit. p_fixed = p_moving +
                  translation; each fixed pixel samples moving at p_fixed −
                  translation. Bilinear sampling requires every contributing
                  pixel to be valid.
                
    
              
    
              
    
                Bounded correlation proposal
                
    
                  
                
    
                
    
                  Search is centered on coincident raster origins, not physical
                  zero translation: t = fixed_offset − moving_offset + (sx·dx,
                  sy·dy). Equal X/Y pixel pitches are required. Minimum overlap
                  uses the smaller input’s valid-pixel count. Integer proposals
                  do not imply subpixel precision. Large requests may require an
                  explicit crop or smaller radius.
                
    
              
    
              
              
    
                Capture fixed and moving analyses to begin.

                Gray is missing overlap; no extrapolation, hole filling or
                implicit crop. TAR contains full numerical arrays, masks, both
                recipes and hashes; raw measurement files are not included.
                Translation and residual metrics do not establish physical
                deformation or certify calibration.
